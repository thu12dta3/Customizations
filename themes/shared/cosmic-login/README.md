# Interface compartilhada

`CosmicScene.qml` implementa a aparência das variantes SDDM e Plasma. Os adaptadores em cada pacote conectam a interface à autenticação nativa. O componente não persiste senhas.

As prévias são capturas da interface Qt Quick renderizada, com uma conta genérica, horário ilustrativo e autenticação desabilitada.
